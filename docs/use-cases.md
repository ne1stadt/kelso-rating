This document describes intended use cases for the kelso-rating site.

Use Cases:
 - Review Kelso Rankings
 - Navigate to User Detailed View
 - Review Kelso Changes in users rating based on event
 - Find user by name or by WCA ID
 - Read about KELSO rating
 - Calculate hypothetical rating based on input times for events
 - Review competition (ended) and changes in ratings of competitors
 - Review competition (ongoing) and estimated rating changes
 - (future) log in from WCA and analysis of personal results
